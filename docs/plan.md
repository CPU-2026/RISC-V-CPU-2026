# 原始实现路线（历史计划）

本页只保留计划，不再重复已过期的“当前实现”。实际进展、未完成项及路线变化见 [process.md](process.md)。

目标：RV32IM乱序执行、按序提交的参数化多发射核心。原工程余量目标为IPC≥1.12、面积≤34,000 μm²、频率≥525MHz，**不是已有测量**；课程门槛见 [template.md](template.md)。

| 周次 | 原计划交付 |
|---|---|
| W1 | 理解周期模拟器、微架构与SystemVerilog模块。 |
| W2～3 | 单发射课程顶层、正确性、性能基线及参数敏感度。 |
| W4～6 | 扩宽取指/译码/分配、执行/写回/旁路和访存。 |
| W7（中期） | 多发射正确性与基线。 |
| W8～9 | 阶段2/3性能与面积权衡。 |
| W10～11 | 结合时序报告收敛RAT/PRF/RS/ROB/BPU/Cache。 |
| W12 | 参数实验、架构总结及交付报告。 |
