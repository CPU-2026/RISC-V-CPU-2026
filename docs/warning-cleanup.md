# Verilator warning 清理（2026-11-07）

已写回工作树，保留当前四宽、ROB16／PRF48 默认及用户已有 PRF 转换修复。
本次没有综合、PPA 测量、软件修改、正式指针重发布、提交或推送。

## 修改原则

- 空接输出接到具名 `unused` 信号；六个使用标量 ready 的 RS 明确接零其未启用的逐 lane ready 输入。
- 显式处理 AXI 物理槽索引、计数零扩展、字节跨度和向量布尔条件，命名原有 generate 作用域。
- 最后一个 ROB bank 的行选择使用原比较必为假的等价分支。
- 保留兼容端口、参数配置共用信号及部分结构字段，不为消除 unused 警告删除功能路径或更改接口。
  175 个声明位置使用局部 `UNUSEDSIGNAL` 标注；另有两个公共辅助模块名、两个刻意混用复位的声明、
  一个单 lane 范围恒真的共享断言局部标注。原断言和所有时序进程的敏感列表均保留。
  **未新增全局 warning 关闭，也未新增位宽、锁存、组合环或范围检查豁免。**
- 经用户单独授权，`scripts/ram/sram_fakeram.sv` 将掩码合并临时值移入纯自动函数；
  仍只有一次非阻塞 RAM 写入，读延迟、字节掩码和禁用／写周期的未定义读输出语义保持。

- 14 种配置在 Verilator 5.040 下以 `-Wall`、不加 `-Wno-fatal` 检查通过，零警告。
- 写回后的真实工作树默认配置在 Verilator 5.020／5.040 下严格检查均零警告。
- 新默认 native／sv2v 各原六项答案正确，两模型 stdout／stderr 完全一致，周期严格匹配当前采用证书：

- SRAM 九种形状的新旧模型差分及独立 word oracle 共 7925 项检查通过。
- 真实 AXIData 新旧全部公开输出差分 6202 次通过，覆盖独立通道背压、满信用、排空和 MMIO；
  读／写接受分别 72／103 次。首轮夹具读覆盖不足的失败保持，追加只读阶段，未降低原断言标准。
- 新的 unused 输入、隐式截断及组合锁存三个负向用例仍被检查器拒绝，证明规则没有被全局关闭。
- sv2v 仅使用既有生成副本 query 标量桥接；通过组合环／锁存门禁，不改生产 RTL 预测或状态方程。

`post-application-verification.json`。r01／r02 失败、并发默认配置变更及重新基准化记录均保留。

这些是有限仿真与 lint 资格，不是全状态形式等价，不代表旧 168 次参数资格或旧 PPA 已重新认证。

`status 2` 已解决；需要更新提交后查看实际评测结果。
