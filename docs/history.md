# 项目历史

## 版本沿革

| 日期 | 主要变化 |
|---|---|
| 2026-11-07 | 放开 16 B 边界的四指令取指；完成 14 组有限配置的[参数实验](参数敏感度分析.md)。 |
| 2026-11-12 | ROB16、PRF48、8 KiB D$ 基线保留完整写回包，加入双队列反向信用。 |
| 2026-11-16 | Load 和 StoreAddr 采用选择性晚唤醒。 |
| 2026-11-17 | Branch 禁用 Load 同拍派发旁路，保留正常写回捕获。 |
| 2026-11-17 | Load 改为独占一路 CDB，MUL/DIV 仍共享一路；原六周期不变，未通过 400 MHz。 |

LSU 地址大小与身份比较的两种独立改写均降频，未采用。独立 postmap、LSU 返回寄存边界、D$ tag 快照和 PRF 并行排名仍未采用。
